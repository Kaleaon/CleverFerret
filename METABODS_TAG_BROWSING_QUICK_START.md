## How to Use

### Basic Workflow

```
1. Open Tag Browser
   ↓
2. Select Tags (one or more)
   ↓
3. Browse Stories
   ↓
4. Download Stories
   ↓
5. Read in Library!
```

### Step-by-Step

#### Step 1: Open Tag Browser
- Open CleverFerret app
- Go to: **Menu** → **Content Creation** → **Fanfiction Downloader**
- Tap: **"Browse Metabods by Tags"** card
- Tag browser opens

#### Step 2: Browse Tags
- See categories: Transformation Types, Genres, Themes, Ratings
- Tap category to **expand**
- Tags show with story counts: "Muscle Growth (1,523)"

#### Step 3: Select Tags
- Tap tags to **select** (chip turns blue)
- Selected tags appear at top
- Select as many as you want
- Remove tag: Tap X icon
- Clear all: Tap "Clear All"

#### Step 4: Choose Match Mode (Optional)
- Tap **filter icon** (top right)
- **ANY mode**: Stories with ANY selected tag (OR logic)
- **ALL mode**: Stories with ALL selected tags (AND logic)

#### Step 5: Browse Stories
- Tap **"Browse Stories"** button
- See matching stories with:
  - Title and author
  - Description
  - Word count and chapters
  - Tags
  - Rating

#### Step 6: Download Story
- Tap **"Download"** button on story card
- Story downloads as EPUB
- Automatically added to library
- Read offline anytime!

#### Step 7: Load More (Optional)
- Scroll to bottom
- Tap **"Load More"** for next page
- Continues browsing

## Advanced Features

### Filtering Options

**Word Count**:
- Set minimum/maximum word count
- Find short stories or epics

**Status**:
- Ongoing
- Completed
- Hiatus
- Cancelled

**Rating**:
- Mature
- Explicit
- Adult Only

**Sort By**:
- **Updated**: Newest updates first (default)
- **Word Count**: Longest/shortest
- **Title**: Alphabetical
- **Chapter Count**: Most/fewest chapters

**Sort Order**:
- **Descending**: Newest/largest first
- **Ascending**: Oldest/smallest first

### Tag Match Modes

**ANY Mode** (Default - OR logic):
- Shows stories with ANY selected tag
- Broader results
- Example: "Muscle Growth" OR "Height Growth"

**ALL Mode** (AND logic):
- Shows stories with ALL selected tags
- Narrower results
- Example: "Muscle Growth" AND "Superhero" AND "Romance"

### Excluding Tags

Want to exclude certain tags? Use advanced filters:
- Select "Erotic" in exclude list
- Browse transformation stories without erotic content

## Troubleshooting

### No Results Found

**Causes**:
- Too many tags selected (ALL mode)
- Tags too specific
- Filters too restrictive

**Solutions**:
- Switch to ANY mode
- Remove some tags
- Broaden filters
- Try different tag combination

### Tags Not Loading

**Causes**:
- No internet connection
- Metabods site down

**Solutions**:
- Check internet connection
- Tap refresh button
- Use common tags (auto-loaded)
- Try again later

### Download Failed

**Causes**:
- Story removed from site
- Connection interrupted
- Site temporarily unavailable

**Solutions**:
- Check story URL in browser
- Retry download
- Try different story
- Check internet connection

### Slow Loading

**Causes**:
- Many results
- Slow internet
- Site traffic

**Solutions**:
- Use pagination (don't load all)
- Wait for load to complete
- Try during off-peak hours
- Use filters to narrow results

## FAQ

### Q: How many tags can I select?
**A**: Unlimited! Select as many as you want.

### Q: What's the difference between ANY and ALL mode?
**A**: ANY = stories with any tag (OR), ALL = stories with all tags (AND).

### Q: Can I save tag searches?
**A**: Not yet, but coming soon! For now, remember your favorite combinations.

### Q: How often are tags updated?
**A**: Tags refresh automatically. Tap refresh button to force update.

### Q: Can I exclude tags?
**A**: Yes, use advanced filters to exclude unwanted tags.

### Q: What if a tag has no stories?
**A**: Tag shows (0) count. Try different tags or check back later.

### Q: Can I search by text too?
**A**: Not in tag browser, but you can use URL download for specific stories.

### Q: Are downloads saved offline?
**A**: Yes! Downloaded EPUB files work offline in your library.

### Q: Does this work for other sites?
**A**: Currently Metabods only. More sites coming soon!

### Q: Is adult content filtered?
**A**: No automatic filtering. Content warnings shown in story ratings.
