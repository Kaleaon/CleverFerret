## 🚀 **Installation Instructions**

### **For Android Devices:**
1. **Download APK**: 
   ```bash
   # Primary APK (Universal)
   /app/builds/universal-media-library-v1.0.apk
   
   # OR Signed Version (Recommended)
   /app/builds/universal-media-library-v1.0-signed.apk
   ```

2. **Enable Unknown Sources**:
   - Go to Settings → Security → Unknown Sources
   - OR Settings → Apps → Special Access → Install Unknown Apps

3. **Install**:
   - Transfer APK to Android device
   - Tap the APK file to install
   - Grant necessary permissions when prompted

4. **Enjoy**:
   - Launch "CleverFerret Universal Media Library"
   - Start importing your media collection!
