## Features Per Section

### Every API Provider Has:
1. **Title** - Provider name
2. **Description** - What it does
3. **API Key Field** - Password-masked input with show/hide
4. **Status Badge** - "Configured ✓" when key is added
5. **Get Key Button** - Direct link to registration page
6. **Documentation Button** - Link to API docs
7. **Optional Note** - Special instructions (if needed)

### Section Headers Include:
- **Emoji Icon** - Visual category identifier
- **Title** - Section name
- **Subtitle** - Brief description
