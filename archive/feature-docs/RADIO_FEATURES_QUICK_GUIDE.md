## 🎯 How to Use: Dynamic Genres

### Adding a Station with Custom Genre

1. Open **Internet Radio** screen
2. Tap **+ button** (top right)
3. Fill in station details:
   - **Name**: "Your Station Name"
   - **URL**: Stream URL
   - **Genre**: Start typing...
4. **Genre field shows suggestions** as you type
5. Options:
   - Select existing genre from dropdown
   - OR type new genre name
   - System offers "Add '[YourGenre]' as new genre"
6. Tap **Add**
7. ✨ New genre **instantly appears** in filter tabs!

### Example Workflow

```
Step 1: Tap + button
Step 2: Enter "Lofi Beats Radio"
Step 3: Enter stream URL
Step 4: Type "Lofi Hip Hop" in genre field
Step 5: See "Add 'Lofi Hip Hop' as new genre"
Step 6: Confirm
Result: New "Lofi Hip Hop" tab appears in genre filters!
```

## 🎨 How to Use: Radio Visualizer

### Basic Usage

1. **Play any radio station**
   - Tap station in Internet Radio screen
   - Music starts streaming
2. **Navigate to Visualizer**
   - Bottom navigation → Visualizer icon
   - OR from player controls
3. **Visualizer automatically activates!**
   - Shows real-time audio analysis
   - Reacts to bass, mid, treble
4. **Try different styles:**
   - Spectrum Bars (frequency bands)
   - Waveform (time domain)
   - Circular (radial patterns)
   - Particles (floating effects)
   - Frequency Rings (concentric circles)

### Advanced Features

**Change Styles:**
- Style dropdown in visualizer
- Seamlessly switch while playing
- Each style reacts differently to audio

**Chromecast:**
- Tap cast icon (top right)
- Select your Chromecast device
- Visualizer appears on TV
- Keep listening on phone or watch visualizer

**Presets:**
- Tap presets button
- Browse pre-configured visualizations
- Apply instantly

## 🎨 Visualizer Styles Explained

### 1. Spectrum Bars
- **Best for:** Electronic, EDM, Hip Hop
- **Description:** Vertical bars react to frequencies
- **Effect:** Bass = tall bars, Treble = short bars

### 2. Waveform
- **Best for:** All genres
- **Description:** Time-domain audio representation
- **Effect:** Shows actual sound wave shape

### 3. Circular
- **Best for:** Ambient, Chill, Lounge
- **Description:** Radial pattern from center
- **Effect:** Pulses outward with audio

### 4. Particles
- **Best for:** Ambient, Classical, Jazz
- **Description:** Floating particles react to audio
- **Effect:** Gentle, organic movement

### 5. Frequency Rings
- **Best for:** Electronic, Experimental
- **Description:** Concentric circles from center
- **Effect:** Rings expand with audio levels

## 💡 Pro Tips

### Genre Organization

1. **Use Sub-Genres**
   - Instead of just "Jazz", create:
   - "Bebop", "Cool Jazz", "Smooth Jazz", "Free Jazz"
   
2. **Language-Based Genres**
   - "French Radio", "Spanish Music", "K-Pop"
   
3. **Mood-Based Genres**
   - "Study Music", "Workout", "Sleep", "Party"

### Visualizer Tips

1. **Match Style to Genre**
   - Ambient → Particles or Circular
   - EDM → Spectrum Bars
   - All-around → Waveform

2. **Chromecast for Parties**
   - Cast visualizer to TV
   - Keep phone for controls
   - Guests see professional visuals

3. **Save Presets**
   - Find combination you like
   - Save as preset
   - Quickly recall later
