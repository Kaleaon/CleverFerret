## 🛠️ **TROUBLESHOOTING**

### **Common Installation Issues**

#### **"App not installed" Error**
```bash
# Solution: Enable installation from unknown sources
Settings > Security > Unknown Sources > Enable
```

#### **Permission Errors**
```bash
# Solution: Grant storage permissions when prompted
# Or manually in Settings > Apps > CleverFerret > Permissions
```

#### **Performance Issues**
```bash
# Solution: Ensure sufficient free storage and RAM
# Clear app cache if needed: Settings > Apps > CleverFerret > Storage > Clear Cache
```

### **Feature-Specific Issues**

#### **Media Files Not Found**
1. Grant storage permissions when prompted
2. Use "Choose Specific Folder" option in Library tab
3. Check if files are in supported formats (see documentation)

#### **Scanning Not Working**
1. Ensure storage permissions are granted
2. Try "Scan Device for Media" from empty state screen
3. Use Storage Access Framework for specific directories
