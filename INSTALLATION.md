# 🧠⚡ CleverFerret Universal Media Library - Installation Guide

## 📦 **APK DOWNLOAD & INSTALLATION**

### **🚀 Quick Installation (5 Minutes)**

1. **Download APK**
   - **For most users**: Download `CleverFerret-v1.0.0-release.apk` (Recommended)
   - **For developers**: Download `CleverFerret-v1.0.0-debug.apk` (Debug version)

2. **Enable Installation from Unknown Sources**
   - Go to **Settings** → **Security** → **Install unknown apps**
   - Or **Settings** → **Apps & notifications** → **Special app access** → **Install unknown apps**
   - Enable installation for your browser or file manager

3. **Install the APK**
   - Open the downloaded APK file
   - Tap **Install** when prompted
   - Wait for installation to complete

4. **Grant Permissions**
   - Open CleverFerret
   - Grant **Storage** permissions when prompted (required for media scanning)
   - Optionally grant other permissions for enhanced features

5. **Start Using**
   - Set up your first media library
   - Scan existing media or import from Calibre
   - Enjoy your universal media library!

## 🔧 **TROUBLESHOOTING**

### **Installation Issues**
- **"App not installed"**: Enable installation from unknown sources
- **"Parse error"**: Download a fresh copy of the APK
- **"Insufficient storage"**: Free up at least 100MB of space

### **Permission Issues**
- **Can't scan media**: Grant storage permissions in Settings → Apps → CleverFerret
- **No media found**: Check that media files are in standard Android directories
- **Crashes on startup**: Restart device and try again

### **Performance Issues**
- **Slow scanning**: Large media collections take time to index
- **High memory usage**: Normal for large libraries, restart app if needed
- **Battery drain**: Disable background scanning in settings
