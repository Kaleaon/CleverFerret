# CleverFerret Auto-Build Repository

This directory contains automatically built APKs that have passed AI code review.

## 🤖 About Auto-Builds

All APKs in this directory are:
- ✅ **AI Reviewed** - Passed comprehensive code analysis
- ✅ **Build Tested** - Successfully compiled and built
- ✅ **Quality Assured** - Meet CleverFerret standards
- ✅ **Auto-Generated** - Built from latest approved changes

## 📱 Installation

1. **Choose an APK** - Download the latest APK file
2. **Enable Unknown Sources** - In Android Settings → Security
3. **Install** - Open the downloaded APK file
4. **Enjoy** - Start using CleverFerret!

## 📋 Build Information

Each build includes:
- **Branch name** - Source code branch
- **Commit hash** - Exact code version
- **AI review score** - Quality assessment (0-100)
- **Build timestamp** - When it was created

## 🔄 Auto-Update Process

New builds are automatically added when:
1. Code is pushed to main/develop branches
2. AI review passes all safety checks
3. Build process completes successfully
4. APK is automatically committed to this directory
