## 🌟 **WHAT IS CLEVERFERRET?**

CleverFerret transforms how you manage, read, watch, and listen to your digital content. It's a **Universal Media Library** that brings professional-grade features typically found only in enterprise solutions to everyone.

### **🎯 Core Capabilities:**
- 📚 **E-Reader**: EPUB, PDF, TXT, HTML, Comics with TTS and full-text search
- 🎬 **Video Player**: Multi-backend system supporting all major formats with professional controls
- 🎵 **Audio Player**: Universal playback with rich metadata and queue management
- 📊 **Calibre Integration**: Import and enhance your existing Calibre libraries
- 🧠 **AI OCR**: Gemini-powered text recognition for older PDFs and scanned books
- 🌐 **65+ APIs**: Comprehensive metadata from specialized music, movie, and book sources

## 🔧 **INSTALLATION & SETUP**

### **Quick Start (5 Minutes)**
1. **Download**: Get the release APK from this page
2. **Enable Installation**: Settings → Security → Install from unknown sources
3. **Install**: Open the downloaded APK file
4. **Grant Permissions**: Allow storage access for media scanning
5. **Setup Libraries**: Scan your media or import from Calibre

### **First Steps**
1. **Explore Interface**: Navigate the four main tabs (Library, Plex & Calibre, Scanning, Settings)
2. **Scan Your Media**: Use the scanning tab to discover existing content
3. **Import Calibre**: Connect your existing Calibre libraries if available
4. **Configure APIs**: Add API keys for enhanced metadata (optional but recommended)
5. **Customize Experience**: Adjust themes, reading settings, and preferences
