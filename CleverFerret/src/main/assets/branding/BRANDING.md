# CleverFerret Branding Pack — generated 2026-10-30 via MakeFox (@makefoxbot)

All art generated by Tinker via the @xynthetix user account (MTProto).
Images: /generate prompts, ~7s each. Animations: /select + /video, 4 tokens
each (12 total; MakeFox balance after: 76 tokens). Raw originals in
`makefox-raw/` (640x768 JPGs, 488x592 5.0s MP4s).

## The mascot
Cream-and-sable ferret, dark mask markings, brass/gold round reading glasses
(or goggles) — "clever" reads instantly. Palette: deep teal + gold on the
main icon; warm amber/orange for the reading/audio pieces.

## Icons (`icons/`)
- `icon_main_*` — PRIMARY app icon candidate: ferret face in a gold ring on
  deep teal, flat vector. Sizes 1024/512/192/144/96/72/48 PNG, center-square
  cropped from the MakeFox original with the full ring preserved.
  Drop-in mapping: 192=xxxhdpi, 144=xxhdpi, 96=xhdpi, 72=hdpi, 48=mdpi,
  512=Play Store listing.
- `icon_alt_*` — alternate: ferret reading a book in a white ring on amber.
  Note: the book cover carries a small stray "C"-like glyph from the
  generator — fine at icon sizes, visible at 1024.

## Illustrations (`illustrations/`)
- `splash_hero.jpg` — ferret librarian with goggles + tablet between the
  shelves. Splash / store-feature / onboarding hero.
- `reader_empty_state.jpg` — ferret reading by lantern light at night.
  Reader empty-state / onboarding.
- `audio_empty_state.jpg` — ferret in orange headphones, paws on a vinyl
  record. Audio/music empty-state / onboarding.

## Animations (`animations/`) — 5.0s loops, MP4 + GIF (400w, 12fps)
- `splash_icon_loop` — the main icon ferret blinks, ears wiggle, glasses
  glint. Splash screen animation.
- `audio_empty_state` — head-bobbing to music, notes swirling.
- `reader_empty_state` — page turn, lantern flicker, sparkles.
