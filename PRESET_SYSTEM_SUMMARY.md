## 📥 How to Get More Presets

### Method 1: Import from JSON

1. Open **Visualizer** screen
2. Tap **Dashboard icon** (📊) in top bar
3. Tap **Download** icon
4. Paste preset JSON
5. Tap **Import**
6. Done! Preset added to library

### Method 2: From Community

**Where to Find:**
- r/CleverFerret subreddit
- Discord server (#visualizer-presets)
- GitHub repository
- Friend's exports

**Example Preset JSON:**
```json
{
  "id": "neon_bass",
  "name": "Neon Bass Spectrum",
  "author": "Community",
  "description": "Bass-heavy neon for EDM",
  "baseStyle": "spectrum_bars",
  "parameters": {
    "sensitivity": 1.5,
    "barCount": 96,
    "bassBoost": 2.5,
    "glowEffect": true
  },
  "colorScheme": {
    "primary": "#00FF00",
    "secondary": "#00FFFF",
    "tertiary": "#FF00FF"
  },
  "tags": ["edm", "bass", "neon"]
}
```

### Method 3: Create Your Own

**Design a preset:**
1. Choose base style (spectrum_bars, waveform, etc.)
2. Set parameters (sensitivity, colors, effects)
3. Export to JSON
4. Share with community!

## 🔧 What You Can Customize

### Base Visualization Types
- Spectrum Bars
- Waveform
- Circular/Radial
- Particles
- Frequency Rings

### Parameters You Can Tweak

**Audio:**
- Sensitivity (0.5-2.0)
- Smoothing (0.0-1.0)
- Bass/Mid/Treble boost (0.5-3.0)

**Visual:**
- Bar count (32-128)
- Colors (custom or theme)
- Glow effect (on/off)
- Mirror effect (on/off)
- Rotation speed (0.5-3.0)

**Advanced:**
- Blend modes (normal, additive, multiply)
- Color cycling speed
- Pulse effects
- Particle count & size
