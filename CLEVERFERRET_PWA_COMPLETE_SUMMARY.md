## 🚀 Quick Start Guide

### 1. Enable Ancient Architect Theme:

**Option A: Replace main app**
```typescript
// In main.tsx
import App from './App-AncientArchitect'; // Use Ancient Architect version

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

**Option B: Integrate into existing app**
```typescript
// In App.tsx
import { ThemeProvider } from '@mui/material';
import { getAncientArchitectTheme } from './components/AncientArchitect';

const theme = getAncientArchitectTheme('ancient-bronze').theme;

function App() {
  return (
    <ThemeProvider theme={theme}>
      {/* Your app content */}
    </ThemeProvider>
  );
}
```

### 2. Use Ancient Components:

```typescript
import {
  AncientCard,
  MediaCard,
  InfoCard,
  PrimaryButton,
  AncientIconButton,
  AncientNavigationRail,
  AncientAppBar,
  MetallicShimmer,
  EnergyPulse,
  CrystalGlow,
} from './components/AncientArchitect';

// Card with pattern
<AncientCard showPattern={true} patternType="diamond" showCorners={true}>
  <Typography>Beautiful content</Typography>
</AncientCard>

// Button with glow
<PrimaryButton onClick={handleAction}>
  Take Action
</PrimaryButton>

// Animated element
<EnergyPulse duration={2} color="#00CED1">
  <Box>Pulsing content</Box>
</EnergyPulse>
```

### 3. Switch Theme Variants:

```typescript
// Ancient Bronze (default)
const theme1 = getAncientArchitectTheme('ancient-bronze');

// Silver Architect
const theme2 = getAncientArchitectTheme('silver-architect');

// Obsidian Tech
const theme3 = getAncientArchitectTheme('obsidian-tech');
```
