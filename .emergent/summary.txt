The CleverFerret - Universal Media Library aims to be a comprehensive manager for various media types (books, movies, music, podcasts, web fiction). Initial requirements included a Plex-inspired UI, extensive metadata retrieval (Google Books, TMDB, MusicBrainz, Podcast Index), and functional media viewers. Core features demanded Calibre-like web fiction management (scraping, downloading) and robust podcast management. Subsequent enhancements focused on advanced media viewers: a VLC-like video player, an e-reader surpassing Moon+ Reader, and a comic reader with panel-by-panel zoom. The latest major demands were an AI-powered content analysis and auto-labeling system, followed by Plex server integration, remote Calibre connection, and cloud storage (Dropbox, Google Drive, Amazon/Google Books). The user also requested an automated build and release system for GitHub, and then identified compilation errors that needed fixing.
