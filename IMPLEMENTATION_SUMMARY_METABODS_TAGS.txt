HOW TO USE
===============================================================================

QUICK START:
1. Open App → Fanfiction Downloader
2. Tap "Browse Metabods by Tags"
3. Select tags (Muscle Growth, Sci-Fi, etc.)
4. Tap "Browse Stories"
5. Download stories you like!

ADVANCED:
1. Select multiple tags
2. Tap filter button
3. Choose match mode (ANY/ALL)
4. Set filters (word count, rating, etc.)
5. Choose sort option
6. Browse results
7. Load more for pagination
8. Download stories
