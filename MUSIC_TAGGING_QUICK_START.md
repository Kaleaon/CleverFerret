## How to Use Tags

### Add Tags to a Track:
```
1. Long-press any track
2. Select "Manage Tags"
3. Wait for AI suggestions (2-3 seconds)
4. Click suggested tags to apply
   OR
5. Browse categories and click tags
6. Done!
```

### Create Custom Tag:
```
1. Open tag management dialog
2. Click "Create New Tag"
3. Enter name (e.g., "Road Trip 2024")
4. Choose category (e.g., COLLECTION)
5. Pick a color
6. Click "Create"
```

### Filter by Tags:
```
1. Go to Music Library
2. Click Filter button
3. Select "By Tag"
4. Choose tag(s)
5. Library shows matching tracks
```

## How to Use Radio

### Add a Station:
```
1. Go to Radio tab (6th tab)
2. Click "Add Radio Station"
3. Fill in:
   - Name: "BBC Radio 1"
   - URL: "http://stream.bbc.co.uk/..."
   - Genre: "Pop"
   - Country: "United Kingdom"
   - Bitrate: "128"
4. Click "Save"
```

### Play a Station:
```
1. Go to Radio tab
2. Click [▶] play button
3. Stream starts
4. Visualizer shows audio
5. Mini player appears
```

### Edit/Delete:
```
1. Click [⋮] menu on station
2. Select "Edit" or "Delete"
```

## Tips & Tricks

### Tagging:
1. **Use AI First** - Let AI suggest, then customize
2. **Create Series Tags** - For soundtracks, themes
3. **Combine Filters** - Tag + Genre + Artist
4. **Color Code** - Use colors for visual organization
5. **Cleanup** - Delete unused tags periodically

### Radio:
1. **Test Streams** - Verify URLs work before saving
2. **Higher Bitrate** - Better quality (192+ kbps)
3. **Favorite Stations** - Put frequently used at top
4. **International Radio** - Discover global music
5. **Save Often** - Backup your station list

## Troubleshooting

### Tags Not Showing?
- Refresh library
- Check tag is applied
- Verify filter settings

### AI Not Suggesting?
- Check Gemini API key is set
- Verify internet connection
- Wait a few seconds

### Radio Not Playing?
- Verify stream URL is correct
- Check internet connection
- Try lower bitrate streams
- Some streams are geo-restricted
