# CleverFerret Media Manager - UI Mockup

A complete, interactive HTML mockup for the CleverFerret media management application.

## Features

### 🎬 Multi-Media Library Management
- **Movies**: Browse and manage your movie collection
- **TV Shows**: Track series and episodes
- **Music**: Organize your music library
- **Books**: Manage your digital book collection

### 🤖 AI-Powered Features
- **Smart Shelves**: AI-generated content collections
- **Dynamic Synopsis**: AI-generated plot summaries
- **Fun Facts**: Interesting trivia powered by mock Gemini API
- **Intelligent Recommendations**: Context-aware content suggestions

### 🎨 Modern UI/UX
- **Responsive Design**: Works on all device sizes
- **Dark/Light Theme**: Toggle between night and day modes
- **Smooth Animations**: Polished transitions and hover effects
- **Focus View**: Detailed item inspection panel

### ⚙️ Comprehensive Settings
- **Appearance**: Theme customization
- **Metadata Agents**: API key management for TMDb, IMDb, Deezer
- **eReader**: Font size and TTS voice settings
- **Playback**: Audio quality and crossfade controls

### 📱 Mobile-First Design
- **Collapsible Sidebar**: Space-efficient navigation
- **Touch-Friendly**: Optimized for mobile interactions
- **Responsive Grid**: Adaptive layout for all screen sizes

## How to Use

1. **Open the File**: Simply open `index.html` in any modern web browser
2. **Navigate Libraries**: Click on Movies, TV Shows, Music, or Books in the sidebar
3. **Explore Content**: Click on any item to view detailed information
4. **Generate AI Shelves**: Use the "Generate AI Shelf" button to create new collections
5. **Customize Settings**: Click the settings icon to access preferences
6. **Switch Themes**: Toggle between dark and light modes in settings

## Technical Details

- **Vanilla JavaScript**: No framework dependencies
- **Tailwind CSS**: Utility-first styling via CDN
- **Lucide Icons**: Beautiful, consistent iconography
- **Mock API Integration**: Simulated Gemini API calls for AI features
- **CSS Custom Properties**: Dynamic theming system
