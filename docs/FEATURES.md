# Clever Ferret Features & Supported Formats

## Supported File Formats

Clever Ferret aims to be a universal media reader.

### eBooks & Documents
- **EPUB:** Full support (EPUB 2 & 3) via Readium.
- **PDF:** Advanced rendering via Readium.
- **DOCX:** Microsoft Word documents (via Apache POI).
- **MOBI / AZW / AZW3:** Kindle formats.
- **TXT / MD:** Plain text and Markdown.
- **RTF:** Rich Text Format.
- **FB2:** FictionBook (basic text extraction).
- **HTML / MHTML:** Web archives.

### Comics
- **CBZ, CBR, CBT, CB7:** Supported via Gemini Comic Service with AI-powered panel detection.

### Audio
- **Audiobooks:** Standard Audiobooks and Readium LCP Audiobooks.
- **Music/Audio:** MP3, FLAC, M4A, OGG, WAV, AAC.

## Key Features

### Reader Experience
- **Customizable Layout:** Margins, line spacing, font size, and font families.
- **Reading Modes:** Day, Night, Sepia, and "Paper" (High contrast/Soft).
- **Immersive Mode:** Distraction-free reading.
- **Navigation:** Chapter navigation, Table of Contents, page slider.
- **Bookmarks & Annotations:** Highlight text, add notes, and bookmark pages.
- **Export:** Export annotations to Markdown.

### AI Enhanced Features
- **AI Insights:** Summaries, character analysis, and thematic analysis for books.
- **Smart Comic Reading:** AI detection of comic panels for guided view.

### Audio & Multimedia
- **Background Playback:** Listen to audiobooks or music while using other apps.
- **Visualizer:** Audio visualizer for music playback.
- **Media Library:** Unified library for all media types.

### Connectivity
- **OPDS:** Support for downloading books from OPDS catalogs.
- **Cloud Sync:** (Planned) Sync progress across devices.
